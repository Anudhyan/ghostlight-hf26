# Ghostlight walkthrough

Record the working application after real inference has been verified. Use only the fictional demo archive. A video walkthrough can satisfy the challenge demo requirement when a hosted site cannot be made accessible to judges.

Suggested length: 60–90 seconds. Show the address bar or local setup briefly, then focus on the application. Narration can be read or replaced with captions.

1. **Introduce the idea (0–10 seconds).**
   “Ghostlight is a memory archive that finds passages by meaning. The open-source model runs in the browser and returns the original text.”
   Show the fictional-sample notice and the initial archive.
2. **Load the actual model (10–25 seconds).**
   Click the model-load control. Capture its real progress or trim the waiting period with a visible edit. State that the first visit downloads model/runtime assets; do not imply this was an offline first load.
3. **Show semantic retrieval (25–45 seconds).**
   Search `music during a power cut`. Show the actual result and its source passage. Then search `how someone taught me to ride`.
   Use the observed ranking and real score. Do not substitute a prepared result or claim the expected ranking if the actual run differs.
4. **Add a fictional memory (45–60 seconds).**
   Add a clearly invented example such as a note about sharing oranges on a train. Search with a related idea. Keep persistence off to demonstrate the session-only default.
5. **Show ownership controls (60–75 seconds).**
   Export the archive as JSON. Point to the persistence and forget controls. Explain that optional browser storage is unencrypted and exported files are separate copies.
6. **Close with the open pieces (75–90 seconds).**
   “Ghostlight uses all-MiniLM-L6-v2, Transformers.js, and ONNX Runtime. The code is open, and the memories remain in their original words.”
   Display the public code repository URL.

Before sharing the video, check that no real family notes, personal file paths, browser credentials, or unrelated tabs appear. Upload the final video somewhere judges can view without requesting access, then add its URL to the DEV post's Demo section if needed.
